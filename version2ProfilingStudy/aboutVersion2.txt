in version2 the goal was set to make the confusion kernel go even more fast with respect to the version1 confusion kernel. the approach was to use float casts of the operands used in the trigonometric and multiplication and addition operations used by the threads executing the confusion instead of the double format. this resulted indeed in a faster kernel as proved by the profiling outputs presented in this folder. the changes characterizing version 2 have been verified by observing the decoded test frame called afterinvConfusion2.png which still presents a low amount of noise (principally due to diffusion) similar to the output obtained in version1 of the application. see the confusion kernel code to see the described changes in detail.
